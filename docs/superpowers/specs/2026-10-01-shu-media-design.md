# Shu 媒体处理规格

## 目标与原版依据

延续用户已授权的完整 Shu 1.2.4 复刻、main 开发和子代理分步实施。原版指南及中文字符串依据见 `docs/SHU_MEDIA_CAPABILITIES.md`。本阶段补齐 MP4/MOV/M4V/3GP 视频转换、高/中/低质量压缩、音频提取与去除、区间剪辑，M4A/WAV/MP3/CAF/FLAC 音频转换，以及视频转 GIF/WebP 动图。Photos 与 LivePhoto 导入导出及视频生成 LivePhoto 由后续相册阶段实现，继续保留在完整核对表；本阶段不代表完整复刻完成。

复用 SwiftUI 文件页、更多页、目标 FolderPicker、系统预览/分享和后台处理模式。保持 iOS 18 部署目标和 iOS 26 系统 Liquid Glass；不新增媒体播放框架或通用任务调度层。视频优先 AVFoundation，音频优先 AVFoundation/AudioToolbox；MP3 使用固定版本成熟 LAME 编码器，必须先核对包和头文件、真实编码再采用。

## 文件与任务安全

所有服务只处理工作区普通文件，拒绝越界、符号链接及祖先、原始 `.`/`..` 路径、非法名称和非目录目标。输入不得改变，结果先在唯一隐藏暂存目录写完，重新打开验证轨道、时长、格式和内容，再用 FileStore.rename/move 同卷无覆盖发布。失败、取消必须清理且不发布部分产物，清理失败明确报错。进度来自已处理的真实媒体时间或帧，不能按定时器伪造；长时间编码需定期响应取消，关闭页面先取消并等待任务结束。

## 音频

输出 M4A 使用 AAC，WAV 使用 16-bit PCM，CAF 使用 PCM，FLAC 使用无损编码，MP3 使用 LAME。保留可表达的采样率、声道顺序和完整时长；PCM 分块读写，内存不随媒体时长增长。M4A/MP3 默认 192 kbps，并提供 64/128/192/256/320 kbps 选项；实际编码器不支持的组合在开始前明确报错，不静默换格式。多声道转 MP3 必须由用户明确选择系统下混至双声道，页面说明此变化，其余支持的容器保持声道数。

输入可来自普通音频或视频的音频轨道。视频有多个音轨时提供明确选择并显示轨道编号/语言；没有音频、损坏文件、不支持的解码器和零长度媒体明确失败。音频转换与提取输出后用真实 PCM 解码比较声道数、采样率、时长和信号内容；有损编码允许合理量化差异，不能用只检查文件非空的测试证明有效。

## 视频

转换容器为 MP4/MOV/M4V/3GP，正确扩展名。默认 H.264 视频和 AAC 音频；选择保留质量时，原轨道兼容目标容器则使用系统 passthrough，否则明确采用 H.264/AAC 重新编码。高/中/低质量分别以最长边 1920/1280/640 为上限，始终不放大输入，保持显示宽高比和方向，编码尺寸采用合法偶数。高/中/低目标视频码率为 8/4/1 Mbps，声轨为 AAC 192 kbps。质量选项是本复刻明确的实现参数，原资源只证明三个等级，不能宣称原版内部码率相同。

保留输入视频方向及完整时间线，所有可表达的音轨与视频同步；目标容器不支持多音轨时，页面要求用户明确选择音轨。静音视频无需伪造声轨。去除音频须存在音轨，输出保留视频、移除全部音频。区间剪辑接受秒数，满足有限值且 `0 ≤ start < end ≤ duration`；输出从零开始并保留该区间的内容、方向及同步。拒绝超范围、空区间、无视频和损坏输入。输出重读必须证明预期轨道、显示尺寸、可解码帧及实际时间范围。

## 视频转动图

用户选择区间、帧率（1–30 fps，默认 10）、GIF/WebP 输出、循环次数（0 表示无限）及原画/最佳/极高/高/中/低质量。原画保持显示尺寸；最佳、极高、高、中、低的最长边上限依次为 1280、960、720、480、320，均不放大。输出帧按区间时间顺序采样，尊重视频方向，末帧时长覆盖区间末尾，GIF 按百分之一秒、WebP 按千分之一秒表达。只播放一次与无限循环的语义必须正确映射到目标格式，不能因缺少循环字段改为无限播放。

时长按累计采样边界量化，避免独立舍入每帧造成总长漂移。每帧量化后须为正；末帧短到目标格式无法表达时明确要求调整区间/帧率，不能写零时长再依赖播放器默认延长，也不能悄悄删除该帧。

颜色选项为全彩、彩色、灰度和黑白：全彩使用编码器默认量化；彩色使用 216 色 web-safe RGB，灰度使用亮度灰阶，黑白使用亮度阈值 0.5。需要成熟编码器处理 GIF 调色板，不自行解析 GIF。复用图片服务的实际编码能力与资源限制：单帧最多 4000 万像素，总帧最多 8000 万像素、最多 1000 帧；开始前显示超限原因并要求调整区间/尺寸/帧率，不能偷偷截断。按帧生成或暂存后释放内存，不同时保留所有未压缩帧。

## 页面与验收

单个视频/音频文件提供对应处理入口；更多页支持系统导入到工作区后打开同一处理页。按操作显示格式、质量、音轨、区间、帧率、循环及颜色控件，提供输出名称和目标目录。后台真实进度、取消等待、失败重试、结果预览/系统分享与文件刷新沿用已有交互。必要的有损变化在表单中说明，不加入与使用无关的实现细节。

真实自检生成有颜色/运动/方向的视频和已知频率、分段内容的音频，覆盖五音频格式、四视频容器、三个质量等级、声轨有无/多音轨选择、提取/去除、区间内容及同步、GIF/WebP 帧内容/时长/循环/颜色、坏输入/非法参数/同名/路径/取消/清理。Mac 运行与 iOS Simulator/Device 编译分开记录；实际 iOS codec 运行必须在应用或测试执行路径取得证据，不能依据 Mac 成功或构建替代。交互测试必须进入真实方法；未经用户明确要求不截图或视觉检查。
