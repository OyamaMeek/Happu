# Shu 本地网络共享设计草案

状态：供用户审阅，尚未实施。网络共享在音频 Task1 完成实施、真实验证和独立审查后优先执行；视频、动图、媒体页面及完整复刻其余范围继续保留。

## 目标与依据

同一 Wi-Fi 或手机个人热点上的电脑，通过浏览器或 WebDAV 客户端操作用户指定的应用目录。原版指南、中文字符串和 Info.plist 的核查见 [需求依据](../../SHU_NETWORK_CAPABILITIES.md)。部署目标继续为 iOS 18，iOS 26 使用现有系统 Liquid Glass。

必须包含浏览、上传、下载、创建目录、删除、共享目录选择、真实访问地址、二维码和明确启动/停止。当前应用的“共享”目录保持本地文件入口；网络服务由单独页面管理，不在应用启动时自动开放。

## 建议交互

“更多”增加“本地网络共享”；目录的操作菜单增加“通过本地网络共享”。两处打开同一个页面，目录菜单预选该目录，更多入口默认工作区的“共享”目录。复用现有 FolderPicker 更换目录。

页面显示目录名称和工作区相对路径、浏览器/WebDAV 模式选择、启动按钮。运行时显示实际地址、复制地址、二维码及停止按钮；更换目录或模式须先停止。一次只运行一种模式，使用系统分配的可用端口，显示实际端口，不承诺固定 8080。

浏览器页面使用中文、本地静态资源，支持目录导航、多文件选择和逐项上传进度、下载、新建目录、确认删除。文件名以文本节点呈现，不能作为 HTML 执行。失败显示对应文件和原因，成功后刷新列表；不依赖外部 CDN。

地址从实际活跃网络接口取得：Wi-Fi/热点优先，IPv6 使用合法 URL 表达；不把回环地址、未指定地址或蜂窝接口地址显示为跨设备访问地址。没有适用接口时提示连接 Wi-Fi 或热点，不能显示虚构地址。二维码编码当前显示的完整访问 URL，切换接口后旧地址失效并更新。

沿用原版的前台使用条件，页面提示共享时保持页面和手机解锁。页面关闭、应用进入后台或锁屏后停止；回到前台保持停止状态，由用户重新启动。停止过程中显示正在停止，资源释放完成后才允许再次启动。

## 推荐实现方式与取舍

推荐采用固定版本的成熟 GCDWebServer HTTP 核心及 WebDAV 扩展，作为本地 SwiftPM 源码包接入。版本采用官方 3.5.4 tag，实施开始时核实 tag 对应提交、源码和许可证，并保存准确来源与局部修改记录；编译和真实请求通过后才能宣布该依赖可用。

浏览器页面使用少量本地 HTML/JavaScript 和该服务的 HTTP 文件接口，复用相同文件操作边界；不接入另一套 WebUploader 页面及其资源依赖。系统 API 负责二维码、网络接口、文件操作和生命周期。保留上游许可证，不增加 CocoaPods 或第二套依赖管理。

这一路径复用现有 HTTP、流式文件和 DAV 协议处理，但上游已归档，默认覆盖和停止行为需要局部修正并持续维护。其公开 stop 不能终止已有请求，不能直接用作本设计的停止完成条件。候选依据：[官方项目](https://github.com/swisspol/GCDWebServer)、[连接实现](https://raw.githubusercontent.com/swisspol/GCDWebServer/3.5.4/GCDWebServer/Core/GCDWebServerConnection.m)。当前只读源码显示请求体读取回调的成功标志需重点核查；它是回归测试线索，尚无本项目运行缺陷结论。

另一路径是基于 SwiftNIO 的 HTTP 服务，再实现 DAV 文件方法；它增加协议实现和依赖范围，当前没有已安装可直接复用的 DAV 服务。纯 Network.framework 路径需要自行处理 HTTP 和 DAV，无法减少需要验证的协议行为。因此本草案推荐前述成熟服务路径。

产品按三个职责组织：NetworkSharingService 管理会话、地址和状态；局部服务适配负责 HTTP/DAV 与受限文件操作；NetworkSharingView 负责页面。浏览器与 DAV 复用同一目录约束，避免分别实现不同安全规则。不重构现有 PDF、图片、归档或媒体服务。

## 文件与协议行为

共享根目录必须是工作区内实际存在的普通目录。所有请求的源和目标都限制在本次共享根目录；拒绝原始或解码后的点路径、非法路径分隔、NUL、符号链接及链接祖先。列举、读取和修改均不开放隐藏项目及内部暂存。路径先进行合法的 URL 解码再逐段校验，不使用字符串前缀判定目录归属。

浏览器上传和 DAV PUT 都将完整请求流式写到本会话的隐藏暂存，再执行无覆盖发布。请求体不完整、连接断开、写入/关闭失败或会话已停止时不得发布。零字节完整文件是合法输入；不能以文件非空冒充请求完整性。

同名上传拒绝并明确显示冲突，保留原文件字节；不自动改名、不静默覆盖。DAV COPY/MOVE 遇已存在目标同样拒绝，按方法返回明确冲突或前置条件失败；不得宣传已支持会覆盖文件的客户端工作流。共享根目录不得删除、移动或覆盖，成功删除子目录需浏览器用户确认。

DAV 覆盖 OPTIONS、PROPFIND（Depth 0/1）、GET、HEAD、PUT、MKCOL、DELETE、COPY、MOVE；正确处理中文/空格名称、文件与目录 href、状态和 multistatus。无限深度查询明确拒绝。Destination 必须属于当前服务且位于共享范围。锁定或未实现方法返回明确不支持，不声明未经验证的完整 Class 2/Finder 兼容性。

文件下载采用成熟文件流和范围响应，HEAD 不传文件内容。浏览器文件列表和 DAV 列举必须看见同一完整结果。修改操作串行执行，发布前核实会话仍有效；停止和新会话不能共享旧请求状态。对校验后的目录替换或链接竞争，需要在操作时再次保障边界并用真实文件替换测试证明，不能只证明请求开始时路径合法。

网络服务遵守显式启动的共享范围。浏览器修改请求校验当前服务来源，不能被任意外部网页调用；不开放任意 CORS。DAV 客户端按正常协议访问。未发现原版密码设置证据，本阶段不新增账号、密码、后台常驻或公网映射功能。HTTP 地址只用于当前局域网，NAT 自动映射关闭。

## 生命周期与失败

状态为停止、启动中、运行中、停止中和失败；只有服务实际监听成功才显示运行及地址。失败必须携带实际原因，不把局域网权限拒绝、无接口和端口/监听失败混为同一个判定。

停止先使会话失效，停止新连接，终止已有连接和在途读写，再等待文件句柄关闭及暂存清理。源库需提供经过测试的连接终止能力；不能把 close 通知或响应错误当作已关闭 socket。若资源释放或清理失败，显示具体错误并保留诊断路径，不能直接写“已停止且清理完成”。

添加与实际服务一致的 NSLocalNetworkUsageDescription 和 Bonjour `_http._tcp` 声明；Bonjour 成功注册、权限实际允许及可连接分别验证。权限状态不能由 Info.plist 声明或 Mac 回环连接推断。

## 验收

1. Mac 对同一产品服务运行真实 HTTP/DAV 请求：中文及空格目录、多文件/空文件上传、完整和范围下载、HEAD、目录创建、删除、COPY/MOVE 与 PROPFIND 内容正确，实际文件逐字节一致。
2. 同名冲突、目录越界、编码点路径、各层链接、隐藏暂存、非法 Destination、删除根目录、并发同名及目录替换均拒绝或按规定处理；范围外 sentinel 和已有文件字节不变。
3. 定长及 chunked 上传中途断开、客户端取消、服务停止、写入/关闭/清理失败均不留下可见部分文件；停止后旧请求不能发布，新连接不能成功，重新启动是独立会话。
4. hosted iOS 测试直接调用产品服务并真实请求，证明该平台 HTTP/DAV 与依赖运行；按 generic Simulator、generic Device、指定模拟器测试构建、安装、运行顺序收取真实退出码和 xcresult，不用 Mac 成功替代。
5. 用户页面路径实际执行：两入口、选择目录、启动、地址复制/二维码内容、停止、关闭重开、后台后保持停止、上传后文件列表刷新。二维码用编码内容断言，未经用户要求不截图或图像检查。
6. 同局域网其它设备、个人热点和局域网权限拒绝单独取得真实设备证据。没有设备条件时准确记录未验证项，不将 loopback、模拟器或 Bonjour 声明计为这几项通过。
7. 任务提交前完成适用构建、共享模块回归及独立规格/质量审查；只提交任务文件，Conventional Commits 和普通 push 遵循已授权工作流。
