# Shu 复刻计划

## 范围

原版 1.2.4 的本地资源确认“文件、下载、更多”三个栏目。首版实现可用的本地文件管理与 HTTP(S) 下载，界面按已知栏目的结构复刻；液态玻璃留待后续。

## 实施

1. 建立可构建的 iOS SwiftUI 工程，使用系统 TabView 与 NavigationStack。
2. 用 Foundation 管理 App Documents 文件；提供文件夹、导入、预览、搜索、重命名、复制、移动、删除和分享。
3. 用 URLSessionDownloadTask 实现下载、暂停、继续、删除与请求头输入；完成后存入 Documents/Downloads。下载列表与完成记录在重启后恢复；中断任务可重新开始。
4. 构建并运行文件操作与下载自检；记录实际支持范围及未验证事项。

不实现原版指南中的多格式转换、解压镜像、局域网服务器和外部 App 集成；这些属于本次用户选定范围之外。
